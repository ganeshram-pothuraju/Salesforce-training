# Salesforce Interview Readiness Bootcamp – Day 4

## Lightning Web Components (LWC)

## Project Overview

Day 4 focused on understanding the fundamentals of **Lightning Web Components (LWC)** and building the first component for the Placement Management System.

The objective was to understand the structure of an LWC, create a basic user interface, deploy it to Salesforce, and prepare it for future enhancements such as data binding, event handling, and Apex integration.

---

## What is LWC?

**Lightning Web Components (LWC)** is Salesforce's modern UI framework based on standard web technologies such as:

- HTML
- JavaScript
- CSS
- Web Components

LWC is used to build **fast, reusable, and responsive user interfaces** that can interact with Salesforce data.
